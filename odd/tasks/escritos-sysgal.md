# Escritos generados en Sysgal
New admin section that shows how many escritos are generated in Sysgal (GEDOC), per period, by lawyer and by tipo, with the detail list. Data from two new ITDS services (delivered 2026-11-12).
Backend: /Users/marcelo/Projects/segal-case-tracker. Frontend: /Users/marcelo/Projects/segal-deudores-web.

- S2. ITDS definitions (verbatim): "cada escrito creado a través de GEDOC desde Sysgal, tanto los de autoservicio (generados por el abogado) como los encargos (solicitados a redacción). Se excluyen los encargos anulados. No existen borradores ni eliminados. Si un documento se regenera, cuenta otra vez. El campo origen indica si es autoservicio o encargo"; "al usuario que lo generó ... un escrito generado por otro usuario (por ejemplo, un procurador) puede traer un id que no esté en esa lista; por eso cada fila trae también el nombre"; "la de generación del documento. Sysgal no registra la fecha de presentación en el tribunal"; "desde el 06-10-2026 ... Los rangos anteriores vuelven vacíos"; "tipo es el código del escrito en GEDOC (por ejemplo, ABANDONO_3_ANOS), y tipo_id puede venir vacío. En ese caso, en por_tipo se agrupan por tipo." Stats are always the whole period (no lawyer/tipo filter); filters only on the list. We show Sysgal's numbers as they come; we never recompute them.
- S3. API, admin only (`require_admin`; lawyer/auditor 403), base `/api/v1/escritos-sysgal`:
  - `GET /estadisticas?desde&hasta` → the unwrapped stats + each `por_abogado` row enriched with `lawyer_id` (`sysgal_usuarios.lawyer_id`, null when unmapped, e.g. a procurador).
  - `GET /listado?desde&hasta[&abogado_id][&tipo_id][&desde_id][&limite 1-500, default 100]` → `{desde, hasta, data:[{id_escrito, id_causa, rol, tribunal, tipo_id, tipo, fecha_generacion, abogado_id, nombre, origen, lawyer_id, case_id}], siguiente_desde_id}` where `case_id` is our case when `sysgal_causas.sysgal_id = id_causa` is linked (one query per page, no N+1).
  - Validation and errors (exact): range > 182 days → 400 "El rango máximo es de 6 meses."; desde after hasta → 400 "La fecha desde debe ser anterior a hasta."; Sysgal failure → 502 "Sysgal no respondió. Intenta de nuevo en unos minutos.".
- S4. Frontend: new admin screen "Escritos generados" (route `/escritos-sysgal`), sidebar entry in the admin group right after "Avance de cartera", same visual language as Avance de cartera (cards, DateField, Consultar, vertical blue charts, tables, CSV). Desde/Hasta default: first day of current month → today; client-side 6-month limit with "El rango máximo es de 6 meses.". Note under the cards (exact): "Cifras de Sysgal (GEDOC). Incluye escritos de autoservicio y encargos a redacción; un escrito regenerado cuenta otra vez. Hay datos desde el 06/10/2026.". Cards: "Total escritos", "Abogados" (rows in por_abogado), "Tipos de escrito" (rows in por_tipo). Charts (chart.js, vertical, theme blue, one per row, full width): "Escritos por abogado" (por_abogado sorted desc) and "Escritos por tipo" (por_tipo sorted desc). Tables "Por abogado" (Abogado, Escritos) and "Por tipo" (Tipo, Escritos). Tipo label: the GEDOC code humanized for display (underscores → spaces, sentence case; e.g. "ABANDONO_3_ANOS" → "Abandono 3 anos"), with the raw code in a tooltip. Listado "Escritos del período" (paginated with siguiente_desde_id, Anterior/Siguiente like the sin-gestión list): Fecha (es-CL date + time), ROL (link to our causa when case_id), Tribunal, Tipo, Abogado (nombre), Origen ("Autoservicio"/"Encargo"); filters by abogado and by tipo (from the stats rows; send abogado_id / tipo_id; a tipo with empty tipo_id is not filterable); "Descargar CSV" downloads every page of the current filter. Empty state for ranges with no escritos: "No hay escritos generados en el período.". Errors shown as returned by the API.
