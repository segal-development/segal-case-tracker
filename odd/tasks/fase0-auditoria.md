## Specs
- S1. Audit findings (verified in prod 2026-11-16): "Abandono disponible: 625 causas, y aparecen en verde ('Al día')" — measured: abandono_disponible true on 625 cases, all semáforo verde. Semáforo distribution: gris 10,972, verde 3,353, rojo 30, amarillo 0.
- S2. Abandono disponible is never "al día": a case with `abandono_disponible = true` gets semáforo `rojo` with the reason text "Abandono disponible: presentar el escrito" wherever the semáforo reason is shown (case list tooltip / detail), unless a signed liberación override applies (the liberación stays authoritative) or the case is `terminada_en_sysgal` (excluded from counts as today). This is computed in the same place the semáforo is computed today (the deadline/semáforo engine) so every view (Causas chips, Inicio, Supervisor, risk board) agrees. An `abandono_disponible` case must also never show the "Al día" label in the detail.
- S3. Fatal deadline expired without a writ: a fatal deadline (the existing fatal set) with status `no_cumplido` and due_date within the last 60 days, not yet reviewed by a human (the existing deadline mark/audit fields: marked_by/marked_at/verdict), makes the case `rojo` with reason "Plazo fatal vencido sin escrito: <tipo> venció el <dd-mm-aaaa>". It stops reddening the case once an admin/lawyer marks the deadline (existing mark endpoint), recording the decision. Deadlines older than 60 days do not redden but are listed (S5).
- S4. Escalation: when a fatal deadline becomes `no_cumplido` (and once for each existing one at deploy via the recompute), create ONE in-app alert per deadline for the case's lawyer(s) AND for every active admin (role admin, e.g. Carla), type `plazo_fatal_vencido_escalado`, title "Plazo fatal vencido sin escrito en <ROL>", body with the deadline type, due date and lawyer; idempotent (never duplicated on recompute). E-mail stays governed by the existing gate (currently off); no Telegram.
- S5. Admin list: `GET /api/v1/cases/plazos-vencidos-sin-escrito` (admin/auditor) returns the fatal `no_cumplido` deadlines not yet marked, newest first, with rol, tribunal, lawyer, tipo, due_date, days since, and whether it reddens the case (≤ 60 days). Shown in the front as a card "Plazos fatales vencidos sin escrito" in Centro operativo (admin/auditor) with a link to each case.
- S6. Recompute and report: a dry-run (`scripts/recompute_semaforo.py --dry-run` or the existing recompute script) reports how many cases change color (verde→rojo for abandono, →rojo for vencidos) and how many escalation alerts would be created; nothing written in dry-run. Apply only after the parent reviews the numbers with Marcelo.
- S7. Strict TDD both repos (RED seen): abandono → rojo with reason; liberación override still wins; vencido fatal ≤ 60 days → rojo until marked, > 60 days not red but listed; marking clears it; escalation alert once to lawyer + active admins, idempotent on recompute; list endpoint admin/auditor only (lawyer/procurador 403); other cases' semáforo unchanged (differential over the existing semáforo tests + a synthetic fixture vs main); front card and reason text.
